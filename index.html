二 我们处理哪些信息

本地剧情与存档

游戏在您设备的本应用专用存储空间内读写剧情进度、存档、已读记录、音量和文字显示设置，用于存档、读档及保存设置。我们不将这些剧情和存档数据上传至服务器，不提供云存档。登录及防沉迷所需的联网处理与剧情存档处理分别进行。 迁移前的 BKE 安卓客户端还保留引擎的本机设备编号接口（UTDID），该编号与 TapTap 账号标识分开；TapTap 登录和认证仅使用 OpenID。

登录信息

为使用 TapTap 账号进入本游戏并关联合规认证状态，我们通过 TapSDK 处理TapTap 提供的账号唯一标识 OpenID、登录授权凭证和登录状态。我们不要求您另行注册独立账号或向我们提交 TapTap 密码，也不额外申请昵称、头像或手机号码。登录授权凭证仅用于完成和维持授权，不用于与本游戏无关的服务。

实名认证与防沉迷信息

实名认证服务可能在您选择的认证流程中处理您的真实姓名、身份证号码等敏感个人信息，用于核验真实身份并落实未成年人保护要求。泄露或不当使用这类信息可能影响您的身份和财产安全，因此我们限制其处理范围和访问权限。

本测试版按“暂无版号”方案接入。我们使用易玩（上海）网络科技有限公司提供的 TapSDK 合规认证服务。您可以在服务支持的情况下使用已实名 TapTap 账号完成认证，或根据认证界面指引提交认证所需信息。上述身份信息由认证服务在必要环节处理，我们不另设真实姓名和身份证填写表，也不另行留存原始身份证号码。

游戏使用玩家账号标识、认证通过或未通过结果，以及允许游玩、时段限制、时长限制或年龄限制等结果执行防沉迷措施；合规认证服务还处理玩家标识、认证会话标识、游玩期间的合规心跳检查、剩余可玩时长以及当前可玩或受限结果。本游戏不获取您的年龄段信息。认证服务仍处理核验身份、16周岁门槛及防沉迷所需信息，游戏依据可玩或受限结果执行限制，不用于营销、画像或剧情推荐。

我们在依法履行实名及未成年人保护义务所必需的范围内处理上述信息；对依法需取得同意、单独同意或监护人同意的环节，会在处理前提供具体说明并取得相应同意。游戏不会将一次隐私政策确认视为所有敏感信息处理已取得单独同意。

SDK 运行所需的信息

为实现登录与合规认证、适配设备并定位相关服务故障，TapSDK 涉及系统版本、设备型号、设备 CPU 信息、网络类型、Android ID、设备内存信息。设备信息由集成在游戏中的 SDK 在相应功能及初始化阶段获取，具体触发和频次见第四部分。 Core 基础依赖还处理 SDK 生成的设备标识及设备元数据，用于基础设备识别；游戏不向 SDK 提供剧情正文或存档文件。

您向本游戏客服邮箱 Support@2pgames.net 发送邮件时，发行方利游会接收发件邮箱地址、邮件中显示的发件人名称、您主动提供的正文及附件，用于答复咨询、排查问题或受理个人信息权利请求。需要开发方协助时，利游会仅转交处理该请求所必需的联系信息、问题描述及相关附件；开发方仅在该范围内协助处理，不将这些信息用于广告、营销或其他无关用途。您不发送邮件不影响正常登录和游玩。请勿发送密码、身份证照片、银行卡资料或与问题无关的他人信息。

三 权限与同意管理

本游戏使用 android.permission.INTERNET（访问网络）和 android.permission.ACCESS_NETWORK_STATE（查看网络状态），用于登录和合规认证。它们通常不会显示 Android 运行时授权弹窗，因此没有弹出系统授权框不表示没有联网或处理信息。 迁移后的 KiriKiri 安卓客户端还声明 android.permission.VIBRATE（振动）权限，用于引擎的振动接口；该权限不用于读取个人信息。

本版本不申请相机、麦克风、位置、通讯录、短信、电话、相册或访问其他应用文件的广泛存储权限。本地存档使用应用专用空间。我们不接入广告、推送、用户行为统计或自动崩溃上报功能。

我们会先展示隐私政策，再在您同意后初始化会收集信息的 TapSDK，并在相应登录及认证场景调用功能。您拒绝同意时，不初始化这些收集组件；您仍可查看政策和联系方式。

如果缺少为完成登录、实名及防沉迷所必需的信息，游戏无法完成相应认证，因而无法提供要求完成认证后才能进入的测试游戏服务。这不构成要求您同意额外收集非必要信息；我们不会捆绑要求广告、统计、营销或无关权限。

您可以通过主菜单 → 设置 → 隐私与账号撤回基于同意开展的处理、退出登录并清除本地授权状态。操作后我们停止相应 SDK 功能，依法仍需保留的记录按第五部分处理。重新进入游戏可能需要再次登录及完成合规认证。

本地存档保存在您的设备应用专用空间，至您删除存档、清除应用数据或卸载游戏时移除。本应用已关闭 Android 系统云备份及设备迁移的数据提取。您在系统外自行制作的副本需自行管理。

TapSDK 官方政策载明境内获取的个人信息存储于中国境内。登录及认证数据仅在实现相应目的所需的最短时间和法定期限内保留：本游戏采用的具体期限或确定方法为本地登录及认证授权缓存保存至您退出登录、撤回同意、清除应用数据或卸载时清理；单次认证许可仅在当前前台游戏会话内有效。由 TapSDK 服务端处理的登录关联及认证记录，按完成账号授权、身份核验和防沉迷所必需的最短期间保留，具体依据处理目的是否仍需实现、适用法律法规、司法程序及有权机关要求确定。您可依第六部分申请删除或撤回；涉及依法需继续保留的记录，停止除必要存储和安全保护外的处理。期限届满后，我们对控制的数据进行删除或匿名化，并在涉及 SDK 数据时协同服务提供者处理。
